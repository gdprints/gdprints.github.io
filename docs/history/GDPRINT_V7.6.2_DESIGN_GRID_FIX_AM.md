# GDprint v7.6.2 — Design services grid fix

Այս տարբերակը հիմնված է v7.6.1 DESIGN SERVICES տարբերակի վրա։

## Շտկված խնդիրը
Դիզայնի 8 ծառայությունների քարտերը տեղադրված էին հիմնական Bootstrap `.row` grid-ից դուրս, որի պատճառով դրանք ամբողջ լայնությամբ դասավորվում էին մեկը մյուսի տակ։

## Փոփոխություններ
- HY `services.html` — դիզայնի 8 քարտերը տեղափոխված են responsive grid wrapper-ի մեջ։
- RU `RU/services.html` — նույն շտկումը։
- EN `EN/services.html` — նույն շտկումը։
