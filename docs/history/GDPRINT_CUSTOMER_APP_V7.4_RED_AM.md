# GDprint ADMIN + Customer App v7.4 RED

Հիմք՝ `GDprint_ADMIN_v7.3.3e_MOBILE_MENU_FULL.zip`

Այս build-ում Admin/Manager/Staff հատվածները պահպանվել են, իսկ `app/` Customer App-ը ստացել է ամբողջական premium dark/red UI։

## Կարևոր
- SQL migration պետք չէ։
- Supabase URL/anon configuration-ը պահպանվել է գործող նախագծից։
- Business logic-ը չի վերագրվել, որպեսզի արդեն աշխատող պատվերների/auth/upload/tracking շղթան չկոտրվի։
- Service Worker cache-ը թարմացվել է `gdprint-customer-v7-4-red` տարբերակով։
