## Ինչ է մաքրվել

- HY / RU / EN ծառայությունների էջերի քարտերը, modal-ները և պատվերի ձևերը
- header / mega-menu / footer ծառայությունների հղումները
- գլխավոր և «Մեր մասին» էջերի ծառայությունների հին տեղեկությունները
- համապատասխան frontend հաշվիչները, կոնֆիգները և order-ID helper-ները
- Customer App-ի catalog-ը, service fields-ը, pricing config-ը և cache-ը
- Manager-ի «Նոր պատվեր» էջի համապատասխան ծառայությունները և հաշվարկները
- Help Center-ի հին ծառայությունների ուղեցույցները և հղումները
- retired ծառայությունների service image ֆայլերը՝ public և app assets-ից
- Admin-ի service catalog / inventory rule տվյալները՝ `044` migration-ով

Մնացել են 12 ակտիվ ծառայություններ՝ լայնաֆորմատ, պլոտերային հատում, այցեքարտեր, լուսանկարներ, բաժակներ, Roll-Up, կտավ, գովազդի տեղադրում, Kinder տուփեր, շապիկներ, X-banner և ինքնակպչուն սթիքերներ։

## Տեղադրում

1. Նախընտրելի է վերբեռնել ամբողջ `v7.6.0 FULL` տարբերակը, որպեսզի հեռացված նկարները նույնպես ֆիզիկապես չմնան server-ում։
2. Supabase SQL Editor-ում գործարկել `supabase/044_retire_18_services.sql`։
3. Կատարել `Ctrl + F5`։ Customer App-ի cache version-ը նույնպես փոխված է `v7.6.0`։
4. Ստուգման համար գործարկել՝

```sql
select public.gd_retired_services_health();
```

`retired_catalog_rows` և `retired_inventory_rules` արժեքները պետք է լինեն `0`։

## Պատմական պատվերներ

Հին պատվերները **չեն ջնջվում**, որպեսզի ֆինանսական և պատվերների պատմությունը չկորչի։ `044` migration-ը արգելափակում է միայն այս 18 ծառայություններով **նոր** պատվերների ստեղծումը։
