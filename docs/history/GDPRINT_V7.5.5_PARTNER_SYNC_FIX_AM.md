# GDprint v7.5.5 — Գործընկերների գրանցման Sync Fix

Խնդրի պատճառը՝ public `partner.html` էջերը հայտը ուղարկում էին FormSubmit/email, իսկ Admin → «Գործընկերներ» էջը կարդում էր Supabase-ի `partner_applications` աղյուսակից։ Այդ երկու հոսքերը կապված չէին։

## Ինչ է շտկվել
- HY / RU / EN գործընկերային հայտերը հիմա նախ գրանցվում են Supabase-ում։
- Admin → «Գործընկերներ» էջը կարդում է պաշտպանված Admin RPC-ով։
- Նոր հայտի դեպքում Admin-ներին ստեղծվում է notification։
- FormSubmit email պատճենը պահպանված է որպես երկրորդական ծանուցում։
- Նույն հայտի browser retry-ի դեպքում 5 րոպեի մեջ duplicate չի ստեղծվում։
- Կարգավիճակի փոփոխությունը կատարվում է Admin-only RPC-ով։

## Տեղադրում
1. Supabase SQL Editor-ում գործարկել `supabase/041_partner_applications_sync_fix.sql`։
2. Upload անել կայքի թարմացված ֆայլերը։
3. Browser-ում Ctrl+F5։
4. Փորձնական նոր գործընկերային հայտ ուղարկել։
5. Admin → Գործընկերներ էջում այն պետք է անմիջապես երևա `Նոր` կարգավիճակով։

## Կարևոր
Մինչ այս fix-ը արդեն FormSubmit-ով ուղարկված հին հայտերը Supabase-ում չեն եղել, ուստի migration-ը չի կարող վերականգնել դրանց տվյալները առանց սկզբնական email/form տվյալների։ Այդ հայտերը կարելի է մեկ անգամ ներմուծել email-ից կամ ձեռքով։
