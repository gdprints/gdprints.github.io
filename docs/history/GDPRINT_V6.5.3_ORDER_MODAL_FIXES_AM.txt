GDprint v6.5.3 — Order Modal Cleanup

Փոփոխություններ
1. Բոլոր պատվերի գրանցման մոդալներից հեռացվել են «Պատկեր/Ֆայլի հղում», «Ֆայլի հղում», Google Drive/Dropbox link և համարժեք URL դաշտերը։
2. Փոփոխությունը կիրառվել է հայերեն, անգլերեն և ռուսերեն Services էջերում։
3. Նույն URL-դաշտերը հեռացվել են Manager → New Order էջից։
4. Իրական ֆայլի վերբեռնման input-ները (type=file) չեն հեռացվել։
5. «Պատվիրել» կոճակը և գինը/արժեքը ցույց տվող հատվածը ամրացվել են մեկ շարքի վրա՝ կողք կողքի։
6. Փոքր էկրանների համար պահպանվել է մեկ շարքը՝ փոքրացված բացատներով և տեքստով։
