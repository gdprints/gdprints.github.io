# GDprint — Service Sync պատուհան

`tools\sync_services.bat` ֆայլը հիմա բացում է փոքր Windows պատուհան։

## Օգտագործում
1. Նախ ամբողջ նախագիծը ZIP-ից Extract արեք։
2. Բացեք `tools` պանակը։
3. Երկու անգամ սեղմեք `sync_services.bat`։
4. Պատուհանում սեղմեք **«Համաժամեցնել հիմա»**։

Պատուհանը ստուգում է `data/services.json`-ը՝ ներառյալ JSON կառուցվածքը, կրկնվող `service key`-երը, HY/RU/EN անունները և նկարների ուղիները։ Եթե ամեն ինչ ճիշտ է, ստեղծվում/թարմացվում է `data/generated/services.catalog.js`։

Եթե սխալ կա, պատուհանը ցույց է տալիս կոնկրետ պատճառը և catalog-ը չի վերագրվում կիսատ տվյալներով։

## Python
Պետք է համակարգչում տեղադրված լինի Python 3 (`py` կամ `python` հրամանով հասանելի)։
